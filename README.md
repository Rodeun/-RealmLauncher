# Realm Launcher

Realm Launcher is a private Minecraft Java Edition launcher project.

## Features
- Microsoft account authentication
- Automatic Java detection
- Minecraft version installation
- Minecraft game launching
- Mod and resource pack management (planned)

## Purpose
This launcher is developed for personal use among a small group of friends.

It is not intended for commercial use or public distribution.
